Daily Puppet Automation Commands
===============================

Command 1: Validate Puppet Syntax
puppet parser validate /etc/puppetlabs/code/environments/production/manifests/site.pp

Command 2: Apply Puppet Configuration
puppet apply /etc/puppetlabs/code/manifests/init.pp

Command 3: List Puppet Resources
puppet resource service

Command 4: Check Puppet Agent Status
puppet agent --test

Command 5: Display Puppet Configuration
puppet config print all

Command 6: Check Puppet Node Status
puppet node status

Command 7: Check AWS Identity
aws sts get-caller-identity --profile default

Command 8: Check SSH Service Resource
puppet resource service sshd

Command 9: Run Puppet Agent in no-daemonize mode
puppet agent --test --no-daemonize --color=false

Command 10: Run Puppet Agent in debug mode
puppet agent --test --debug

Command 11: List Installed Puppet Modules
puppet module list

Command 12: List AWS Systems Manager managed instances
aws ssm describe-instance-information --query 'InstanceInformationList[].{InstanceId:InstanceId,PingStatus:PingStatus,PlatformName:PlatformName}' --output table

Command 13: List Amazon S3 buckets
aws s3 ls --profile default

Command 14: Display the Puppet agent environment
puppet config print environment

Command 15: Display the Puppet agent certname
puppet config print certname

Command 16: Display the Puppet server setting
puppet config print server
